# CubeShot

Начало 2D-игры на C++17 и SDL3 с отдельными клиентом и сервером.

Сейчас клиент открывает окно **960 × 540** с тёмным фоном, полом внизу
и одним синим квадратом **48 × 48** — персонажем, стоящим на полу.
Персонаж двигается влево и вправо по полу и не выходит за границы арены.
Прыжки, гравитация, стрельба и сеть пока не реализованы.
Сервер остаётся заглушкой: выводит сообщение и завершается.

Идея на будущее: два игрока-кубика на общей арене с платформами,
ходьбой, прыжками и оружием (изначально — пистолетом с одиночными выстрелами).
Кроме ходьбы, эти механики пока остаются планами.

## Структура

```text
CubeShot/
├── CMakeLists.txt      # Сборка и подключение библиотек
├── src/
│   ├── game/           # Игровые сущности и правила, без зависимости от SDL
│   │   ├── Types.h                # Vec2, Rect, PlayerId
│   │   ├── Player.h / .cpp         # Состояние и движение игрока
│   │   ├── PlayerInput.h          # Действия игрока
│   │   ├── Bullet.h               # Состояние будущей пули
│   │   ├── Weapon.h / .cpp         # Параметры оружия и таймер
│   │   ├── Arena.h / .cpp          # Границы, платформы, точки появления
│   │   ├── World.h / .cpp          # Владение миром и его обновление
│   │   └── Collision.h / .cpp      # Пересечения и ограничения движения
│   ├── client/         # Работа с SDL3
│   │   ├── main.cpp               # Точка входа
│   │   ├── Application.h / .cpp    # Окно, ресурсы SDL и главный цикл
│   │   ├── Input.h / .cpp          # Клавиатура → PlayerInput
│   │   └── SceneRenderer.h / .cpp  # Отрисовка World
│   ├── server/         # Подключения игроков и управление матчем
│   └── network/        # Форматы сообщений, упаковка и передача
├── assets/
│   ├── textures/       # Текстуры
│   ├── sounds/         # Звуки
│   └── fonts/          # Шрифты
├── maps/               # Арены, платформы и точки появления
├── tests/              # Проверки игровой логики
├── build/              # Результаты сборки, исключены из Git
├── README.md
└── .gitignore
```

Объявления находятся в `.h`, реализация функций — в `.cpp`.
`Types`, `PlayerInput` и `Bullet` — простые структуры данных без методов,
поэтому отдельные `.cpp` им пока не нужны.

| Сущность | Ответственность |
| --- | --- |
| `Player` | Идентификатор, положение, скорость, размер, здоровье, оружие; горизонтальное движение |
| `Bullet` | Положение, скорость, урон, идентификатор стрелявшего; пока только данные |
| `Weapon` | Урон, скорость пули, интервал выстрелов и оставшееся время ожидания; стрельбы пока нет |
| `Arena` | Границы, платформы (сейчас только пол) и точки появления |
| `World` | Хранит игроков, пули и арену; принимает ввод по ID и обновляет игроков |
| `Collision` | Проверка пересечения прямоугольников, ограничение движения границами и боками платформ |
| `PlayerInput` | Направление движения; поля прыжка, выстрела и прицеливания зарезервированы на будущее |

Поток данных: `Input → PlayerInput → World → Player/Collision`, затем
`SceneRenderer` читает состояние мира и рисует его. Игровая библиотека
`cubeshot_game` доступна клиенту, серверу и тестам, но не использует SDL.
Сервер пока не запускает симуляцию.

Скорость персонажа — 280 пикселей в секунду. Клиент обновляет мир с шагом
1/120 секунды независимо от частоты отрисовки. После длительной задержки
учитывается не более 0,1 секунды, чтобы персонаж не перемещался резким скачком.

## Сборка

Нужны CMake 3.16 или новее, компилятор с поддержкой C++17, инструмент
сборки (например, Make или Ninja) и установленная **SDL3 3.2 или новее**
с заголовками и пакетом CMake (`SDL3Config.cmake`). SDL2 не подходит.
SDL3 подключается только к клиенту.

Из папки проекта выполните:

```bash
cmake -S . -B build
cmake --build build
```

Если CMake не находит SDL3, укажите каталог её установки:

```bash
cmake -S . -B build -DCMAKE_PREFIX_PATH=/путь/к/SDL3
```

## Запуск

Для стандартной сборки на Linux:

```bash
./build/bin/cubeshot_client
```

Для клиента нужна графическая сессия. Запуск сервера для просмотра сцены
не требуется. Заглушку сервера можно запустить отдельно:

```bash
./build/bin/cubeshot_server
```

При использовании генератора с несколькими конфигурациями (например,
Visual Studio) укажите `--config Debug` при сборке. Программы появятся
в `build/bin/Debug/`, на Windows с расширением `.exe`.

## Управление

- **A / ←** — идти влево.
- **D / →** — идти вправо.
- Отпустите клавиши, чтобы остановиться. Два противоположных направления
  одновременно также останавливают персонажа.
- При потере фокуса окна персонаж останавливается.
- Закройте окно стандартной кнопкой закрытия, чтобы завершить клиент.

Используются физические клавиши A/D, поэтому управление работает и при
русской раскладке.

## Тесты

Тесты проверяют движение и остановку, границы арены, независимость движения
от частоты обновления, столкновения и таймер оружия. Они работают без окна и SDL.
После сборки запускайте их так:

```bash
(cd build && ctest --output-on-failure)
```

Чтобы отключить сборку тестов, передайте `-DBUILD_TESTING=OFF`
при настройке CMake.
