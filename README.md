# CubeShot

Каркас будущей игры на C++17 с отдельными клиентом и сервером.
Оба приложения пока выводят сообщение и завершаются. Окно, ввод, отрисовка,
сеть и игровые правила будут добавлены позже.

## Структура

```text
CubeShot/
├── CMakeLists.txt      # Сборка и подключение библиотек
├── src/
│   ├── game/           # Общая игровая логика
│   ├── client/         # Окно, ввод, отрисовка и работа клиента
│   ├── server/         # Подключения игроков и управление матчем
│   └── network/        # Форматы сообщений, упаковка и передача
├── assets/
│   ├── textures/       # Текстуры
│   ├── sounds/         # Звуки
│   └── fonts/          # Шрифты
├── maps/               # Арены, платформы и точки появления
├── tests/              # Проверки игровой логики
├── build/              # Результаты сборки, исключены из Git
├── README.md
└── .gitignore
```

## Сборка

Нужны CMake 3.16 или новее, компилятор с поддержкой C++17 и инструмент
сборки (например, Make или Ninja). Внешних библиотек пока нет.

Из папки проекта выполните:

```bash
cmake -S . -B build
cmake --build build
```

## Запуск

Для стандартной сборки на Linux:

```bash
./build/bin/cubeshot_server
./build/bin/cubeshot_client
```

При использовании генератора с несколькими конфигурациями (например,
Visual Studio) укажите `--config Debug` при сборке. Программы появятся
в `build/bin/Debug/`, на Windows с расширением `.exe`.

## Управление

Управление пока не реализовано. После добавления ввода здесь появится
список клавиш для движения, прыжка, стрельбы и меню.

## Тесты

CTest подключён; реальные тесты появятся вместе с игровой логикой.
После сборки запускать их можно так:

```bash
(cd build && ctest --output-on-failure)
```

Чтобы отключить сборку тестов, передайте `-DBUILD_TESTING=OFF`
при настройке CMake.
