# feat: предсказание движения и выстрелов — 0.7.0

При задержке сети свой персонаж и пуля теперь отображаются сразу. Клиент
симулирует движение общей физикой 120 Гц, затем согласует его с сервером и
повторяет неподтверждённый ввод. Здоровье, попадания и счёт остаются авторитетными.

Ввод передаётся 60 Гц с резервными командами; сервер ограничивает очереди и
обрабатывает максимум одну команду за тик. Надёжные прыжки и выстрелы имеют
идентификаторы, снимки подтверждают обработку, предварительные пули удаляются
без дублирования. Смерть и смена раунда очищают предсказание.

Протокол повышен до 2: требуется обновить одновременно клиента и сервер.
Полный rollback попаданий не входит в эту версию.

Проверка: Linux клиент+сервер — 9/9 CTest; сервер без SDL — 6/6 CTest.
Включены проверки replay, мгновенной пули, ограничений истории и UDP-дуэли
с базовым RTT 150 мс, джиттером до 30 мс и потерями 5%.
Windows проверяется существующим GitHub Actions после публикации ветки.
