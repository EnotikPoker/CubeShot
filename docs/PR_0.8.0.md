# feat: интернет-дуэли, общие серверы и быстрый матч — 0.8.0

В «Мультиплеере» теперь доступны список общих серверов, быстрый матч и
сохраняемый ник без регистрации. Оба способа подключения используют одно
атомарное бронирование: два одновременных запроса не занимают один слот.
HTTP работает в фоне; отмена освобождает также поздно полученную бронь.

Новый `cubeshot_online_server` без SDL обслуживает пул независимых дуэлей,
каталог и одноразовые256-битные токены на10секунд. Вход без действительной
брони отклоняется. Готовность, раунды до5 побед, реванш и серверный урон
сохранены. Выход любого участника отменяет матч и освобождает место,
но не завершает общий сервер. LAN и интернет имеют разные пути навигации.

Протокол3: в handshake добавлены ник/бронь, в снимки — отображаемые имена.
Подготовлены systemd/Caddy, HTTPS и инструкция `docs/ONLINE.md`.
Без настроенного адреса сервис обозначен как ненастроенный; LAN/Тест доступны.

Проверено на Linux:11/11 CTest с клиентом,8/8 без SDL;31единица трансляции
без предупреждений-Wall/-Wextra/-Wpedantic. Интеграционные сценарии охватывают
конкуренцию, повтор/отмену/TTL токенов, полный пул, рестарт, порт, ники,
HTTP/UDPбой и недоверенный TLS-сертификат. Два отдельных SDL-клиента с отдельным
серверным процессом прошли меню, ники, quickmatch, Ready, арену, Esc и выход.
