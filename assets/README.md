# Графические ресурсы CubeShot 0.15

`effects.png` (1536×1024, RGBA) — шесть столбцов, четыре строки:
огонь 0–5, брызги крови 6–11, дым 12–17, вспышка 18, взмах 19,
искры 20, небольшая плоть 21, крупная плоть 22, подпалина 23.
`materials.png` (1774×887) — четыре столбца, две строки:
металл, камень, трава, земля, нейтральная оболочка персонажа, плоть,
бумага, тёмная панель. Эти два исходных растровых атласа созданы для проекта
с помощью OpenAI imagegen 30 октября 2026 года. Они хранятся в репозитории;
сборка не обращается к генератору изображений.

`font.png` и `src/client/FontAtlas.h` — заранее запечённые Rubik 450/650,
ASCII, кириллица и знаки интерфейса. Исходный вариативный шрифт:
[Google Fonts / Rubik](https://github.com/google/fonts/tree/main/ofl/rubik),
`fonts/Rubik.ttf`, лицензия SIL OFL 1.1 в `fonts/OFL.txt`.
Лицензия входит в каждый игровой архив. Для изменения набора символов
отредактируйте `tools/bake_visual_font.py`, затем выполните:

```bash
python3 -m pip install Pillow
python3 tools/bake_visual_font.py
```

Pillow нужен только автору атласа. Обычная сборка и игра используют готовые
PNG, SDL 3.4 и встроенный PNG-декодер без SDL_image/SDL_ttf.
`cubeshot_assets` копирует папку рядом с клиентом при сборке, install и
`package_game.py` включают её в дистрибутив. Ресурсы ищутся относительно
исполняемого файла, независимо от текущего рабочего каталога. При их
отсутствии клиент показывает ошибку; сохраняйте папку целиком.

Полупрозрачные элементы атласа рисуются пакетами по текстуре. Вершины
статического фона и платформ кешируются на время жизни рендера и карты.
Геометрия сколов и останков создаётся модулем `game/Shape` без зависимости
от SDL; клиент использует именно этот контур, а не самостоятельную маску.
