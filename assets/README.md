# Графические ресурсы CubeShot 0.15

`effects.png` (1536×1024, RGBA) — шесть столбцов, четыре строки:
огонь 0–5, брызги крови 6–11, дым 12–17, вспышка 18, взмах 19,
искры 20, небольшая плоть 21, крупная плоть 22, подпалина 23.
`materials.png` (1774×887) — четыре столбца, две строки:
металл, камень, трава, земля, нейтральная оболочка персонажа, плоть,
бумага, тёмная панель. Эти два исходных растровых атласа созданы для проекта
с помощью OpenAI imagegen 30 октября 2026 года. Они хранятся в репозитории;
сборка не обращается к генератору изображений.

Шрифт интерфейса — `fonts/Rubik.ttf` из
[Google Fonts / Rubik](https://github.com/google/fonts/tree/main/ofl/rubik),
лицензия SIL OFL 1.1 в `fonts/OFL.txt`.
С 0.16.0 текст рисуется SDL3_ttf3.2.2/FreeType под фактическое разрешение
окна; увеличение маленьких запечённых символов удалено. Кеши текста и шрифтов
принадлежат конкретному renderer, ограничены по размеру и учитывают DPI.
Физический текстовый проход сохраняет logical presentation, viewport и clip.

SDL3_ttf, FreeType и лицензии включаются в готовые архивы вместе со шрифтом.
Пользователям ничего доустанавливать не нужно. Для нативной разработки есть
`python3 tools/bootstrap_ttf.py`: сборка в `build/_prefix`, требуются SDL3 и
FreeType с заголовками. Обычный игровой билд не требует Pillow.

`cubeshot_assets` копирует папку рядом с клиентом; install и package включают
её в дистрибутив. Ресурсы ищутся относительно исполняемого файла, независимо
от рабочего каталога. При отсутствии ресурсов клиент показывает ошибку.
Сохраняйте папку целиком. PNG читаются встроенным декодером SDL3.4.

Статический фон и платформы кешируются, эффекты рисуются пакетами по текстуре.
Тела используют чистый цвет и общий физический контур; локальные разломы,
текстура плоти на останках и обугливание не являются независимыми наклейками.
